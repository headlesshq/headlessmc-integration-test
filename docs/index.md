# HeadlessMc integration tests

These pages show what [HeadlessMc](https://headlesshq.github.io/headlessmc/) commands print and which files they change.
They are generated from the recordings of the
[integration tests](https://github.com/headlesshq/headlessmc-integration-test),
which run every command against the headlessmc jar and native images on Linux, Windows and macOS.

See [Commands](commands/index.md).
